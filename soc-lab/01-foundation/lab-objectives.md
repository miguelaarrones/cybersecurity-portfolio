# SOC Lab - Objectives

## Purpose

I am building this lab to learn cybersecurity by doing practical exercises.

My main goal is to learn SOC analysis first and then use that knowledge as a base for DFIR and malware analysis.

---
## What I Want to Learn

### Security Monitoring

Understand how events are generated on a computer and how they can be collected and viewed from a SOC.

Examples:
- Login attempts
- Process execution
- File changes
- Network activity
- System changes

### Alert Investigation

Learn how to investigate an alert instead of assuming that an alert automatically means an attack.

For each investigation I want to answer:
- What happened?
- When did it happen?
- Which machine was involved?
- Which user was involved?
- Where did the activity come from?
- What evidence do I have?
- What information am I missing?

### Detection

Learn how security tools identify suspicious activity and how detections can produce false positives.

Later I want to create and test my own detections.

### Incident Response

Learn the basic steps taken after suspicious activity is confirmed, such as investigation, containment, and recovery.

### DFIR

Use the SOC lab as a starting point for learning how to investigate computers after an incident.

### Malware Analysis

Later, create a separate environment for learning how malware behaves and how to analyze it safely.

---
## Portfolio

The lab will also be used as a portfolio to show practical work.

The main things I want to document are:
- Lab setup
- Security detections
- Investigations
- Timelines
- Lessons learned
- Scripts and useful commands

The portfolio will grow as I learn.
